# PP1 · Guía conectada

1. Descomprimí la carpeta completa.
2. Abrí index.html con Chrome o Edge. La navegación y el código funcionan sin conexión.
3. Alternativamente, abrí la carpeta en VS Code y ejecutá index.html con Live Server.

Los PDFs se abren dentro de la guía o en una pestaña nueva. Si tu navegador no permite incrustarlos desde un archivo local, usá Abrir PDF o Live Server.

No requiere instalar dependencias ni ejecutar Symfony. Es una guía independiente: no modifica SISTEMA_AUTOS_PP1.

## Contenido
- index.html, estilos.css, app.js: página y navegación.
- datos.js: uniones documentales y copia del código consultado.
- pdf/: los 19 PDFs originales, con nombres simplificados.
- assets/: vistas de los dos diagramas originales.
- codigo/: copia de consulta de PHP, Twig y configuración; no es un proyecto Symfony ejecutable.
